# E-Commerce Sales & Customer Analysis (MySQL)

## Project Overview

This project analyzes a real-world e-commerce dataset using MySQL to answer business questions related to revenue, customer behavior, order status, and regional sales performance.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Demonstrated

- SELECT
- WHERE
- COUNT()
- SUM()
- GROUP BY
- ORDER BY
- INNER JOIN
- CASE Statements
- Aggregate Functions

## Business Questions Solved

- What is the total revenue?
- How many total orders exist?
- Which states have the most customers?
- What is the order delivery status?
- Which states generate the highest sales?
- How can customers be segmented based on spending?
